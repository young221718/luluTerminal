# luluTerminal macOS 첫 버전

승인: 2026-10-19, 도넛형 v3 화면과 개발 진행 요청. 표시 브랜드 luluTerminal, 내부 식별자 InfraTerminal 유지.
목표는 약 10대의 Linux 서버 상태를 보며 계정별 터미널 작업을 다시 여는 macOS 앱이다.
추가 승인: 2026-10-19, 현재 Mac을 항상 표시하고 바로 사용할 수 있는 로컬 셸을 제공한다.
UI 변경: 2026-10-19, 도넛 중앙에 작은 숫자를 넣고 사용률 구간별 색을 연속 그라데이션으로 표시한다.

브랜딩 적용: 2026-10-19, 올루루 아이콘과 네이비·민트 색상을 적용하며 화면 배치·서버 행·계정 탭 동작은 유지한다.

## 동작 계약

1. 서버 프로필은 UUID, 연결 종류(`local`/`ssh`), 이름, 호스트 또는 SSH 별칭, 포트, 계정 목록, 모니터링 계정을 가진다. 기존 v1 JSON에 연결 종류가 없으면 `ssh`로 읽는다. 비밀번호·개인 키 원문은 저장하지 않는다. SSH 연결은 시스템 OpenSSH와 SSH agent/사용자 SSH 설정을 사용하며 호스트키 확인을 무력화하지 않는다.
2. 왼쪽 목록은 48~52pt 행에 서버 이름, 상태, CPU/RAM/디스크/GPU/VRAM 도넛 5개를 표시한다. 열 제목은 한 번만 표시한다. 22pt 도넛 중앙에 8pt 보조색 정수 사용률을 표시하며 % 기호는 생략한다. 링은 0–100% 원형 눈금에 고정된 연속 그라데이션으로, 0–50% 민트에서 70% 노랑·85% 주황·100% 빨강으로 이어지고 현재 사용량까지만 채운다. 툴팁·접근성 이름·상세에는 단위를 유지한다. GPU 미지원/미수집/실패는 —로 표시해 0%와 구분한다.
3. 서버를 선택하면 그 서버의 탭을 표시한다. 탭 제목에 계정과 작업 이름을 함께 표시한다. 서버별 마지막 선택 탭과 순서를 앱 재실행 후 복원한다.
4. SSH 앱 탭마다 서버+계정에 종속된 고유 원격 tmux 세션을 둔다. 탭마다 별도 세션을 사용해 같은 세션을 여러 클라이언트에서 선택할 때 생기는 창 전환 간섭을 방지한다. UUID에서 만든 세션 식별자는 화면 제목 변경과 무관하다. 서버 UUID·계정 UUID·탭 UUID를 포함하며 shell 입력을 섞지 않는다.
5. SSH 새 탭을 만들 때만 원격 세션을 생성한다. 재접속은 기존 세션만 붙이며 세션이 없으면 명시적으로 알린다. 사용자가 새 세션 만들기를 선택하기 전 자동 재생성하지 않는다. 다른 클라이언트를 강제 detach하지 않는다.
6. SSH 탭 닫기는 로컬 보기와 SSH 연결만 닫는다. 원격 tmux 작업은 종료하지 않는다. 닫힌 탭을 로컬 기록에 보존해 다시 열 수 있다. 원격 세션 종료 기능은 첫 버전에 넣지 않는다. 앱 종료·네트워크 단절 후 원격 서버와 tmux가 살아 있으면 작업을 이어간다. 서버 재부팅·프로세스 종료는 복원 보장 밖이다.
7. Ghostty 전체 엔진을 AppKit NSView에 임베딩한다. 명령 실행·PTY·렌더링은 Ghostty가 맡고 UI는 SwiftUI/AppKit을 사용한다. HTML 터미널이나 가짜 출력으로 구현을 대체하지 않는다. 엔진을 구할 수 없으면 빌드/화면에 분명히 표시한다.
8. 앱 실행 중 별도 SSH 명령으로 Linux `/proc/stat`, `/proc/meminfo`, `/proc/net/dev`, `df -Pk`, 선택적 NVIDIA `nvidia-smi`를 수집한다. 사용자 터미널에 명령을 타이핑하지 않는다. SSH는 비대화형·시간 제한·호스트키 검증 유지. 선택 서버 목표 2초, 나머지 10초; 수집은 서버별 중첩하지 않고 동시 실행을 제한한다.
9. CPU는 두 표본의 total/idle counter 차분. RAM은 MemTotal-MemAvailable. 디스크는 루트 파일시스템부터. GPU와 VRAM은 장치별 수치에서 전체 GPU 평균, VRAM 총량 가중 비율을 기본 표시한다. 상세에 장치·네트워크 인터페이스별 값을 제공한다. 네트워크는 monotonic counter 차분/실제 시간. 초기 표본·재부팅·counter 감소·0분모·잘못된 응답은 계산 불가로 표현한다.
10. 표본에 수집 시각을 기록한다. 수집 주기 3배 이상 지나면 마지막 값과 갱신 중단을 표시한다. 실패를 정상 0으로 바꾸지 않는다. 차트는 앱 실행 중 표본만 사용하며 재실행/긴 공백을 선으로 연결하지 않는다.
11. 서버 추가·편집, 계정 선택, 모니터링 계정 선택, 연결/해제/재접속, 닫은 탭 다시 열기, 자원 상세, 설정을 제공한다. Ansible은 예정 메뉴와 비활성 필드만 제공한다.
12. 기본 목록 맨 위에 현재 Mac을 한 번만 고정 표시하며 일반 서버 편집으로 변경하거나 제거할 수 없다. 실제로 비어 있는 첫 실행에서는 로컬 Mac과 기본 셸 탭을 선택한다. 기존 원격 서버 선택·계정·탭·닫힌 기록은 유지한다. 명시적 데모에는 가상 서버 10대와 실제 로컬 Mac을 구분해서 표시하며 가상 서버로 SSH를 실행하지 않는다. 데모는 실사용 저장 파일을 변경하지 않는다.
13. 저장은 버전 있는 JSON을 앱 Application Support에 원자적으로 기록한다. 손상 파일을 기본값으로 덮어쓰지 않고 오류와 복구 경로를 표시한다. SSH 로그인 계정 변경은 기존 탭의 계정 정체성을 조용히 바꾸면 안 된다.
14. 로컬 Mac은 예약한 서버·계정 UUID를 사용하고 현재 로그인 이름을 표시한다. 로컬 탭은 현재 로그인 셸을 홈 디렉터리에서 실행하며 SSH·tmux 명령에 진입하지 않는다. 선택한 로컬 탭은 바로 사용할 수 있도록 셸을 연다. 탭 전환은 기존 Ghostty surface를 재사용한다. 새 탭·닫기·다시 열기를 지원하지만 로컬 탭을 닫거나 앱을 종료한 뒤에는 새 셸을 시작하며 작업 지속을 보장하지 않는다.
15. 로컬 지표는 권한 추가 없이 macOS API로 CPU counter 차분, 물리 RAM, 홈 디렉터리가 속한 단일 볼륨 용량을 수집한다. RAM 사용량은 `(active + inactive + wired + compressed) × pageSize`이며 회수 가능한 캐시를 포함한다고 표시한다. Activity Monitor와 같은 사용량이라고 주장하지 않는다. APFS 공유 용량은 홈 볼륨 한 번만 읽고 여러 볼륨 값을 합산하지 않는다. 로컬 GPU·VRAM·네트워크는 미지원으로 표시하며 nil 또는 빈 배열을 유지한다. 로컬 지표와 셸은 원격 수집·SSH 실행 경로와 분리한다.

| 인자 안전 | 호스트/계정/포트 검증, 공백·개행·셸 기호/옵션 주입 거부; 원격 문자열 올바른 인용 |

## 검증 경계

로컬 자동 테스트, 앱 빌드·실행, 실제 SSH 서버, NVIDIA GPU, 서명/공증·배포를 별도로 보고한다.
실서버는 사용자가 테스트 대상을 지정/승인하기 전 접근하지 않는다. 원격 collector 설치와 Ansible 실행은 후속 범위다.
