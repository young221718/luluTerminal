## 2026-10-26 서버 목록 드래그 UX

- macOS 27에서는 기존 ScrollView/LazyVStack·서버 행을 유지하고 시스템 `reorderable`·`reorderContainer`를 적용했다. 최종 단일 행 이동만 기존 원자적 저장 경로에 전달한다. 이전 macOS는 명시적 행 미리보기와 동작 줄이기를 반영한 0.18초 최종 전환을 사용한다. 실행 최소 버전은 14이며 새 UI API를 컴파일하려면 macOS 27 SDK가 필요하다.

- 한글 검색어 일치와 marked-text 정책 검사는 실제 한국어 IME 후보 선택·조합 확정/취소 전체 수락을 대신하지 않는다. VoiceOver·Intel 기기·장시간 메모리 추이·Developer ID 공증은 이번 결과에 포함하지 않는다.
